# Schedule

The Schedule turns tasks with planned dates into a concrete daily time plan. It
shows one day on smaller screens and three days on wide screens.

## Planning the day

- Review tasks whose date range includes a visible day but that do not yet have
  a valid single-day time slot.
- Review incomplete overdue tasks in a separate tray.
- Drag a task from the tray into the 24-hour grid to assign its day and time.
- Select a task and enter exact times in the inspector instead of dragging.
- Existing scheduled tasks share lanes when their times overlap.

## Adjusting scheduled work

- Drag an event to move it within the day or to another visible day.
- Drag either edge to change its start or end time.
- Edit the task name, description, dates, times, completion state, or delete the
  task from the inspector.
- Navigate one day backward or forward, return to today, and optionally hide
  completed tasks.

In **Leaf tasks only** mode, only tasks without children can be scheduled
directly.
