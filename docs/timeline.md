# Timeline

The Timeline combines the hierarchical task tree with a 28-day project plan.
Task bars show planned start and end dates alongside the task that owns them.

## Task hierarchy

- Create top-level tasks and child tasks.
- Rename tasks directly in the task column.
- Drag tasks to reorder siblings, nest them below another task, or promote them.
- Use the keyboard arrow controls on the reorder handle for the same operations.
- Expand or collapse individual branches, or use **Collapse all** and
  **Expand all**.
- Resize the task-name column on desktop.

## Planning

- Click an empty date cell to schedule an unscheduled task on that day.
- Drag a task bar to move its date range.
- Drag either edge of a bar to change its start or end date.
- Move the visible range backward or forward by four weeks, or return to today.
- Hide completed tasks with **Hide done**.

## Task details

Selecting a task opens the inspector. It can change the name, description,
planned dates and times, mark the task done or reopen it, or delete the task and
its children.
In **Leaf tasks only** scheduling mode, parent dates are calculated from their
children and cannot be edited directly.
